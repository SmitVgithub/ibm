### Request Flow

```mermaid
sequenceDiagram
  actor Visitor as 🧑 Visitor
  participant Browser as Web Browser
  participant CDN as CDN
  participant StaticHost as Static Host
  participant EmailSvc as Email Service

  Note over Visitor,StaticHost: Flow 1 - Portfolio Page Load
  Visitor->>Browser: Navigate to portfolio URL
  Browser->>CDN: GET index.html
  CDN-->>Browser: Return cached HTML
  Browser->>CDN: GET CSS / JS / Images
  CDN-->>Browser: Return static assets
  Browser-->>Visitor: Render portfolio page

  Note over Visitor,EmailSvc: Flow 2 - Contact Form Submission
  Visitor->>Browser: Fill in contact form fields
  Visitor->>Browser: Click Submit
  activate Browser
  Browser->>EmailSvc: POST form data (name, email, message)
  activate EmailSvc
  EmailSvc-->>Browser: 200 OK - Submission received
  deactivate EmailSvc
  Browser-->>Visitor: Show success confirmation message
  deactivate Browser
  EmailSvc->>EmailSvc: Forward message to portfolio owner email

  Note over Visitor,CDN: Flow 3 - Asset Cache Miss
  Visitor->>Browser: Navigate to projects section
  Browser->>CDN: GET project images
  CDN->>StaticHost: Cache miss - fetch from origin
  StaticHost-->>CDN: Return assets
  CDN-->>Browser: Deliver assets and cache
  Browser-->>Visitor: Display project gallery
```
